# Foundation surface brief

Mode: Operate. Scope: the existing Electron workspace shell, reusable kit and
theme; page composition and feature modules remain assigned to Stage 1.
Authority: the user supplied Linear world in DESIGN.md and master-build-brief.md.
The user reconfirmed the scope and selected code-first construction on October 1.
No concept tournament is needed for this precisely specified foundation.

## Direction contract

THESIS: Make the daily workspace readable and consistent through a shared shell,
typed registries and one component language. Preserve every working flow.

OWN-WORLD: Linear charcoal surfaces, hairline separation, local Inter and
JetBrains Mono, compact 14px body text, 8/12px corners and 4px spacing. Lavender
belongs to the brand, primary actions and focus; data heatmaps use its derived ramp.

STORY: The owner sees today's activity, moves to a task, and completes it locally.
Empty and loading states explain the next useful step without invented records.

FIRST VIEWPORT: Retain sidebar, breadcrumb and greeting, with the annual calendar
immediately below the greeting. Keep Start focusing visible at the header. Neutral
selected navigation and a measured collapsible sidebar anchor orientation.

FORM: Existing application topology; user-pinned Linear adaptation, no seed roll.
Signature interaction: keyboard command navigation within the local workspace.
Motion: functional 120–200ms transitions, disabled for reduced motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
