## Direction contract

- Thesis: a quiet local workspace where the next action is clear, and the same
  task flows from its board into a scheduled daily queue and a focus session.
- Own world: inherit Tempo's current fonts, solid accents, light and dark themes,
  native desktop shell, and local-first storage. Replace only selected surfaces.
- Story: choose work on the board, schedule it, focus, then see recorded progress.
- First viewport: bounded top search, concise heading, visible primary content;
  all due habits visible without opening sections. No promotional explanations.
- Form: four compact task lanes, flat check-in rows, open document canvases,
  real line charts, table-based project navigation, compact focus preset buttons.
- Finish: retained data and controls, keyboard alternatives to dragging, no
  horizontal page overflow, responsive light/dark evidence and an independent
  review. Design and UX target 9.9/10; do not manufacture a score or confuse a
  source build with installed owner-data acceptance.

Study must retain progress bars, learned/total topic counts, recorded time and
the current topic beneath each curriculum. Journal must be comfortable without
entering writing mode. Review uses the chosen weekly report and real line charts.
Keep historical plans/reflections even when their old evening form is removed.
The canonical Task date/time drives Plan; completing it there completes that Task.

codex/habits-work-1.7. Statistics remains unchanged until new options are selected.
