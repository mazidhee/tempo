# Knowledge workspace production direction

October 8, 2026. Operate; Read inside notes. Code-led extension of Tempo's
existing workspace. Notes A and floating timer E are approved. The owner asks
for compact scale across Tempo, including the sidebar; five scale previews are
available, with a default percentage still pending. Existing profiles retain
100% until the owner selects a value in Settings.

## Thesis

Notes opens at a folder library; writing, links and a real-record graph join the
existing daily workspace. Home's composition and original waveform stay intact.

## First viewport

Nested folders sit beside an open note list. Search is visibly bounded near the
top. Creation actions are quiet, labelled text controls. A note opens a wide
canvas with a wrapping title, contextual formatting and restrained metadata.

## System

Inherit Inter, existing neutral light/dark palettes, accent tokens, Lucide icons,
keyboard focus and page conventions. Exact upstream Yoopta MIT toolbar CSS is
vendored with notices; Tiptap remains the editor. No AI or combined app engines.

## Signature interaction

Saved note references connect real notes, topics, curricula and work projects.
The collapsible right graph panel settles a force layout, supports pan/zoom and
opens selected records. Sidebar order is persistent. Review leaves navigation;
saved reviews remain accessible in Settings. Statistics remains metrics-only.

## Native Focus

E is a small, draggable, resizable, always-on-top session card. It controls the
same authoritative Focus run, with pause/resume, Open Focus, Hide and adjustable
35–100% opacity. Hidden windows do not stop the timer. Bounds and opacity survive
restart. Interface scale is an open preference, applied to the whole workspace.

## Data and verification

SQLite retains semantic notes; atomic Markdown mirrors use stable IDs under
`notes/<folder>/`. External conflicting edits are preserved. Local draft recovery
and backup import retain records. Do not reimport Rehab or restore older owner
data. Validate desktop/light/dark/390px views, native timer controls, two restarts,
backup idempotence and current owner records before a Windows release. No 9.9
design claim is established by these checks.
